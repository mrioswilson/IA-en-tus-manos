El laboratorio se distribuye en **paquetes completos de GitHub Releases**. El ZIP automático «Source code» de GitHub sirve para estudiar fuentes y **no contiene el programa autónomo ni el modelo**. Usa los botones de la portada para elegir tu sistema.

El programa autónomo incluye Qwen3.5 2B Q4_K_M, llama.cpp y Electron. Extrae todos los archivos, abre la aplicación y espera la carga del modelo. Después de descargarlo funciona sin Internet y sin instalar Python, Ollama o Node.js.

Esta edición pública mantiene la aplicación base 4.0.0-rc2 y actualiza documentación y textos para el uso individual. Conserva las cuatro experiencias y 05 · Apuesta. No cambia modelo, motor, cálculos ni controles. Las plataformas son experimentales y requieren validación física e institucional de esta edición. La prueba personal anterior de Windows corresponde a rc1. El problema de carga reportado en Apple Silicon sigue pendiente de comprobación. No hay firma del distribuidor ni notarización Apple.

El sitio no ejecuta el modelo ni requiere cuentas. No incorpora analítica, rastreadores, cookies propias ni recursos remotos obligatorios para la presentación. GitHub presta el alojamiento y distribuye los archivos.

El código educativo de la web, presentación y laboratorio se distribuye bajo MIT. Tipografía, modelo y componentes conservan sus respectivas licencias. Las fuentes correspondientes Electron/FFmpeg viajan dentro de cada paquete completo. El árbol laboratorio/ permite estudiar el código de la aplicación.
