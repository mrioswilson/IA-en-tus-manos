# La IA en tus manos: dentro de la caja negra

Universidad Adolfo Ibáñez — Universidad Abierta 2026. Santiago de Chile.
Sábado 7 de noviembre de 2026, 12:15–13:45.

Extrae todo el ZIP y abre **index.html**. La presentación animada de 18 láminas funciona sin Internet, cuentas, servidor ni instalación. Mantén juntas css, js y assets.

→ / espacio avanza · ← retrocede · R reinicia · G abre el mapa · F solicita pantalla completa · M reduce movimiento · H muestra ayuda.

Cada estudiante descarga y ejecuta su propio laboratorio y realiza las cuatro misiones: predicción, contexto, temperatura e historia. La presentación ilustra los mecanismos; la aplicación descargada obtiene los resultados reales localmente.

- PRESENTACION_RESPALDO.pdf: 18 páginas estáticas.
- TARJETAS_MISIONES.pdf y tarjetas_individuales/: cuatro misiones individuales A4.
- GUIA_DESCARGA.pdf: siete pasos visuales para Windows.
- PROGRAMA_TALLER.pdf y .md: horario actualizado.
- GUIA_FACILITADORES.pdf: preparación y acompañamiento.
- GUION_PRESENTADOR.md: relato y controles de las 18 láminas.
- COMO_PRESENTAR.md: instrucciones para la exposición.
- imprimibles.html: versiones editables e impresión en grises.
- PRUEBA_INSTITUCIONAL.md: comprobación en un computador administrado, pendiente.
- FUENTES_Y_CREDITOS.md: fuentes científicas, ilustraciones y licencias.
- MANIFEST.sha256: integridad de los materiales del ZIP offline.

La presentación no ejecuta un modelo. La aplicación autónoma se distribuye por separado en ZIP completos mediante GitHub Releases; incluye modelo y runtime. No se descarga desde el ZIP automático del código fuente de GitHub.
