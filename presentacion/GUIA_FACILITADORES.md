# Guía para facilitadores

Cada estudiante usa su propio computador y realiza individualmente las cuatro misiones. El ciclo es **Predecir → Experimentar → Explicar**.

Antes del taller, validar un computador institucional con el usuario habitual: descarga, extracción completa, ejecución, inicio de procesos, puerto local loopback, carga del modelo y guardado de resultados. Registrar versión y SHA-256. Repetir una consulta sin red. Si una política bloquea el programa, pedir autorización al soporte universitario; mantener activas las protecciones. Conservar una copia local auditada de respaldo.

Preparar la presentación offline, comprobar las láminas 4, 8 y 10 y abrir el PDF. No se necesita audio. La presentación no realiza inferencias.

Conservar el programa: Martín 12:15–12:24; Joaquín 12:24–12:42; instrucciones 12:42–12:45; descarga, extracción y carga 12:45–13:00; misiones de diez minutos desde las 13:00, 13:10, 13:20 y 13:30; discusión y cierre 13:40–13:45.

1. **Predicción:** 05 · Apuesta. Usar opciones ilustrativas para pensar sin porcentajes. Escribir el token y revisar el espacio inicial. El botón confirma y genera en una sola acción; revelar después.
2. **Contexto:** 02 · Cambia una palabra. Predecir, consultar dos frases, modificar una y volver a comparar.
3. **Temperatura:** 03 · Controla la imaginación. Consultar después de mover T y generar varias continuaciones. Temperatura no es inteligencia ni veracidad.
4. **Historia:** 04 · Tú eres la IA. Abrir las posibilidades, elegir tokens sucesivamente y usar La IA continúa. Comparar las elecciones humanas y las del modelo.

Quien termine antes la descarga puede empezar la misión 1. Si la descarga se extiende, priorizar predicción, contexto y temperatura; los tiempos de descarga son orientativos. Mantener los 18 minutos de Joaquín.

Si el motor falla, reintentar una vez o usar el respaldo explícito rotulado PREPARADO. Son resultados reales guardados; no presentarlos como inferencia en vivo. Si la app no puede abrirse por una política, registrar el bloqueo y recurrir al soporte.

Compartir historias individuales voluntariamente. Si queda tiempo, hacer una construcción conjunta breve con el laboratorio proyectado. Guardar antes de reiniciar o cerrar.

Comprobación institucional: **pendiente**. Ver PRUEBA_INSTITUCIONAL.md. La prueba personal de Windows rc1 no acredita esta edición ni un computador administrado.
